# Riset — 03 · Atlasway Travel (Global & Contemporary)

Posisi: agen digital multi-destinasi (Jakarta · Bali · Yogyakarta) dengan nuansa *command centre* / SaaS. Berikut insight → keputusan desain. Semua sumber di bawah dibaca pada tahap riset; angka tidak dikutip kecuali tertulis pada judul sumber.

| # | Insight | Keputusan desain |
|---|---------|------------------|
| 1 | Baymard: fitur pencarian "booking" harus menjadi konten utama beranda situs travel — judul riset menyebut banyak situs masih tidak melakukannya. [Baymard](https://baymard.com/research-articles/travel-accommodations-booking-search) | Hero *command deck* navy: konsol pencarian 7 kolom selalu terlihat di viewport pertama; nilai jual hanya 5 kolom. Tidak ada konten pemasaran sebelum pencarian. |
| 2 | Baymard: hasil pencarian akomodasi paling mudah dibandingkan pada tata letak daftar dengan filter dan penyaringan yang jelas (rating bintang/fasilitas). [Baymard — split view](https://baymard.com/research-articles/accommodations-split-view), [Travel UX best practices](https://baymard.com/research-articles/travel-site-ux-best-practices) | Inventori memakai **baris horizontal 12 kolom** (4 foto · 5 matriks spesifikasi · 3 panel harga) menggantikan kartu vertikal 3 kolom; filter sticky di kiri dengan chip fasilitas. |
| 3 | Design system (Apple HIG, GitLab Pajamas, Primer): segmented control dipakai untuk memilih **satu** dari beberapa pilihan yang berkaitan dan harus selalu ada satu aktif. [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/segmented-controls), [Pajamas](https://design.gitlab.com/components/segmented-control), [Primer](https://primer.github.io/design/components/segmented-control) | Mode *Stays Inventory / City & Island Tours* = segmented tab di puncak konsol; hanya tampil jika kedua modul aktif, dan selalu ada satu mode terpilih (kontrak pencarian Ortasys). |
| 4 | Tren dashboard SaaS B2B 2026: grid bento modular, token warna, minim chrome, data padat tapi terstruktur. [Orbix — bento grid](https://www.orbix.studio/blogs/bento-grid-dashboard-design-aesthetics), [TheKitBase — tren 2026](https://thekitbase.app/blog/saas-dashboard-design-trends-2026), [idealogic — prinsip dashboard](https://idealogic.io/blog/dashboard-design) | Seksi "Kapabilitas platform" = bento 12 kolom bergaya spec-sheet (label mikro huruf kapital, status titik, chip teknis) di atas navy; sisa situs tetap terang agar fokus transaksi. |
| 5 | Dashboard yang baik menjawab satu pertanyaan utama dalam hitungan detik (uji 5 detik). [idealogic](https://idealogic.io/blog/dashboard-design) | Konsol punya **3 langkah bernomor** (Tujuan → Tanggal → Tamu) dan satu CTA dominan; bilah status API di dasar konsol memberi umpan balik sistem tanpa mengganggu. Teks status diberi label ilustratif. |
| 6 | SNAP (Standar Nasional Open API Pembayaran) ditetapkan Bank Indonesia; QRIS adalah standar kode QR nasional BI + ASPI; DOKU mendokumentasikan integrasi SNAP/QRIS. [BI — SNAP](https://www.bi.go.id/id/layanan/Standar/SNAP/default.aspx), [ASPI — SNAP](https://aspi-indonesia.or.id/standar-dan-layanan/standar-open-api-pembayaran-indonesia-snap), [DOKU — QRIS](https://developers.doku.com/accept-payments/direct-api/snap/integration-guide/qris) | Kapabilitas "SNAP BI / DOKU" ditampilkan faktual (QRIS, virtual account, kartu via DOKU hosted fields) tanpa klaim "terpercaya ribuan" atau sertifikasi tambahan. Nama pemasok tidak ditampilkan (aturan Ortasys). |
| 7 | Identitas SaaS/travel digital modern: ikon geometris hub-and-spoke, biru tua + satu aksen sejuk, tipografi geometris-grotesk, foto sejuk (cool grade). (Sintesis dari riset 1–4; tidak meniru identitas OTA tertentu — sesuai DESIGN.md.) | Logo: lingkaran hub dengan 3 titik orbit (navy + teal). Plus Jakarta Sans + Inter. Foto Jakarta/Bali/Yogyakarta dengan gradasi warna dingin; teal hanya aksen. |

## Catatan aksesibilitas turunan
Teal #2C9A91 hanya 3,42:1 pada putih → teks memakai `accentText` #247D76; biru #3978B9 hanya 4,28:1 pada background → teks memakai #3672B0. Di atas navy, teks aksen memakai teal terang turunan. Dokumentasi lengkap di `brand-dna.json`.
